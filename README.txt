WEBSITE PORTOFOLIO KIMIA — SIFAT KOLIGATIF LARUTAN

CARA MEMBUKA:
1. Ekstrak file ZIP ini.
2. Buka folder website_sifat_koligatif.
3. Klik dua kali file index.html.
4. Website akan terbuka di browser.

STRUKTUR:
- index.html dan file HTML lain: setiap bagian memiliki halaman terpisah.
- assets/style.css: desain dan tampilan website.
- assets/app.js: menu, navigasi Previous/Next, dan progress.

CATATAN EDIT:
- Buka tentang-saya.html untuk mengganti nama, kelas, dan nomor absen.
- Halaman video berisi tautan pencarian YouTube agar kamu bisa memilih video yang sesuai.
- Website menggunakan Google Fonts; koneksi internet diperlukan agar font eksternal tampil. Website tetap dapat dibuka tanpa internet, tetapi font akan menggunakan font cadangan.
- Seluruh halaman dapat dibuka secara lokal tanpa instalasi atau database.
